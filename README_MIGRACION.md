# Migración a Astro - Portal Laboratorios UNET

## Comandos principales

```bash
npm.cmd install
npm.cmd run dev
```

Si ya tienes un proyecto Astro creado, puedes copiar estas carpetas encima del proyecto actual:

```text
src/
public/
```

## Organización

```text
src/components   -> partes reutilizables
src/layouts      -> estructura base de las páginas
src/pages        -> páginas del portal
src/styles       -> CSS general
public/assets    -> imágenes y archivos estáticos
public/js        -> JavaScript normal
```
